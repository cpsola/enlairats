# Enlairats — 3D print guide

Printable STL parts for the physical edition of **Enlairats**.

> **Status:** folder layout is ready. STL files and photos will be added here soon.
> Until then, use this document as the intended structure and checklist.

## What’s in the box

| Part | Folder | Notes |
| ---- | ------ | ----- |
| 4 building miniatures (×4 of each height) | `stl/buildings/` | Heights 1–4 |
| Board / play surface | `stl/board/` | 4×4 grid for miniatures |
| Clue tokens (1–4) | `stl/clues/` | Border clues |
| Box body, lid, and logo insert | `stl/box/` | Storage |

Photos of a finished print will live in `photos/`.

## Recommended print settings

_To be filled when the STLs are published_ (filament, layer height, infill, supports, orientation, scale checks).

## Assembly

1. Print all parts.
2. (Optional) sand / finish.
3. Place the board, sort buildings by height, and store clue tokens in the box.
